# Variflight 2 Steplife
一个简单的工具将**飞常准**轨迹转换为**一生足迹**轨迹  
**所有**处理仅在设备端

[戳我](https://l1-an.github.io/Variflight2Steplife/)立即体验

相比原来的 Kotlin 版本, 现在无需通过编译器运行 main 函数而是直接在网页上点击按钮即可完成转换操作.
